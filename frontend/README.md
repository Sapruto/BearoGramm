# BearoGramm Front-End

## Setup:

### Prerequisites:
- `node`
- `npm`
- `yarn`

### 1. Install the packages:
```sh
yarn
```

### 2. Run the application
```sh
yarn dev
```

## Stack:
- styling: `sass` & `tailwindcss`
- routers: `react-router-dom`
- client state: `zustand`
- server state: `@tanstack/react-query`
- http client: `axios`
- component library: `MUI`
- icons: `lucide`
